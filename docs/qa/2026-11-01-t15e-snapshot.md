## Steps

Scripted end-to-end (no hand taps): `scripts/android/qa-snapshot.sh`
(run `t15e-snapshot-20261101-122243`, `EXIT=0`, `qa-snapshot PASS`).

1. Install the APK, push the host snapshot to the app-private snapshots dir.
2. Cold boot 1 with the `snapshot_in` intent extra; wait for
   `session_snapshot_in=` + `session_resume pc=` in logcat.
3. Let the restored game run 60 s untouched; screenshot before/after.
4. Open the Menu overlay, tap Save snapshot; wait for `snapshot_saved path=`.
5. Open the Menu overlay (swipe to reveal bottom rows), tap Load snapshot;
   wait for `snapshot_loaded path=` + `session_resume pc=`.
6. Cold boots 2 and 3 with the `snapshot_in` extra; wait for resume each time.
7. Push a 12-byte corrupt file over the snapshot, boot with `snapshot_in`,
   expect a named snapshot error and a stopped session.
8. Re-push the good snapshot so the device is left working.
