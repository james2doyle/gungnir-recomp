## 2 — AAudio smoke

```sh
adb shell am force-stop com.gungnir.recomp
adb logcat -c
adb shell am start -n com.gungnir.recomp/.GungnirActivity --ez audio_smoke true
adb logcat -d | grep audio_smoke
```

The smoke opens an AAudio low-latency 44.1 kHz S16 stereo stream, submits a
440 Hz tone through `MixerSink`, renders the synthetic VAG fixture through
`SasCore` (first sample 1023), submits it and waits 500 ms:

```text
I gungnir : audio_smoke ok=1 vag=1 pulled=23820 underrun=13324 xruns=0
I gungnir : audio_smoke_result=true
```

Expected: the stream starts, the mixer is pulled, the VAG render matches the
hand-computed sample, and AAudio reports no xruns. Actual: pass for those
checks.

`underrun=13324` is not a soak result: the smoke queues about 230 ms of audio
once and then waits 500 ms, so the ring is intentionally empty for the last
~270 ms. The meaningful device metric here is `xruns=0` on the AAudio stream.
