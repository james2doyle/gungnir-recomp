## 2 — AAudio smoke

```sh
adb shell am force-stop com.gungnir.recomp
adb logcat -c
adb shell am start -n com.gungnir.recomp/.GungnirActivity --ez audio_smoke true
adb logcat -d | grep audio_smoke
```

The smoke opens an AAudio low-latency 44.1 kHz S16 stereo stream, renders
the synthetic VAG fixture through `SasCore` (first sample 1023), pre-fills the
ring, then feeds 256-frame 440 Hz tone blocks every 4 ms for the requested
duration. `clean=1` requires both `MixerSink` underruns and AAudio xruns to be
zero.

Three-second run:

```text
I gungnir : audio_smoke ok=1 vag=1 clean=1 duration_ms=3000 pulled=133896 underrun=0 xruns=0
I gungnir : audio_smoke_result=true
```

Sixty-second soak:

```text
I gungnir : audio_smoke ok=1 vag=1 clean=1 duration_ms=60000 pulled=2647610 underrun=0 xruns=0
I gungnir : audio_smoke_result=true
```

Expected: the stream starts, the mixer is pulled continuously, the VAG render
matches the hand-computed sample, and neither the mixer nor AAudio reports an
underrun. Actual: pass on the physical phone.

The soak is audio-clock only. It does not run the guest at 59.94 Hz, so the
game-loop pacing part of TC-12.2 remains T13.

## Named gaps

- The 60 s soak is clean but runs on the audio clock, not the 59.94 Hz guest
  loop; game-loop pacing and game audio are T13.
- The VAG is a synthetic constant-nibble fixture, not game audio; it proves
  the SasCore -> mixer -> AAudio path only.
- Game audio is wired when the HLE reaches the Android shell (T13).
- No emulator run: the reproducible AVD starts with `-no-audio`.
